# Александр — разработчик и аналитик данных

Создаю приложения для macOS, инструменты автоматизации и аналитические проекты.
Работаю со Swift, AppKit, Python, SQL и превращаю идеи в понятные работающие продукты.

## Приложения

### [KeySwitch](https://github.com/Andrles/KeySwitch)

Нативное офлайн-приложение для macOS, которое автоматически исправляет слова,
набранные в неверной русской или английской раскладке.

- Swift и AppKit
- автоматическое распознавание русского и английского языков
- проверка орфографии и исправление очевидных опечаток
- локальная обработка без отправки введённого текста в интернет
- установщик, автоматическая сборка и GitHub Releases

[Скачать последнюю версию](https://github.com/Andrles/KeySwitch/releases/latest)
