# Аналитика данных

[← На главную](https://github.com/Andrles)

Учебные и исследовательские проекты: анализ данных, продуктовые метрики и статистические эксперименты.

## Проекты

| Проект | Задача и методы | Доступность данных |
| --- | --- | --- |
| [A/B-тест алгоритма рекомендаций](https://github.com/Andrles/ab-test-recommendation-algorithm) | Дизайн эксперимента, расчёт выборки, проверка статистической значимости, оценка вовлечённости | Исходные данные не опубликованы; доступны код и сохранённые результаты |
| [Анализ продаж интернет-магазина](https://github.com/Andrles/online-retail-analysis) | Очистка транзакций, выручка, сезонность, товары и страны | Открытый датасет UCI; загружается при запуске |
| [SQL-анализ вовлечённости доноров](https://github.com/Andrles/donor-engagement-sql) | PostgreSQL, CTE, JOIN, сегментация, проверка качества данных | Учебная база недоступна; сохранены запросы и результаты |
| [Анализ факторов конверсии](https://github.com/Andrles/conversion-analysis) | Поведение посетителей, сегментация, сезонность и конверсия | Открытый датасет UCI; загружается при запуске |

## Инструменты

SQL, PostgreSQL, Python, pandas, NumPy, SciPy, statsmodels, matplotlib, seaborn и Jupyter Notebook.
