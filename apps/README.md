## KeySwitch

Офлайн-утилита для macOS, которая исправляет слова, набранные в неверной русской или английской раскладке. Работает в строке меню и обрабатывает ввод локально.

- **Платформа:** macOS 13+, Apple Silicon и Intel.
- **Технологии:** Swift, AppKit.
- **Возможности:** автоматическое исправление раскладки, ручное переключение, проверка орфографии, исключения для приложений.

[О проекте](https://github.com/Andrles/KeySwitch) · [Скачать](https://github.com/Andrles/KeySwitch/releases/latest) · [Сообщить об ошибке](https://github.com/Andrles/KeySwitch/issues)

## BMW Import

Локальный калькулятор стоимости ввоза BMW из Китая в Россию. Объединяет покупку, таможенные платежи, доставку и подготовку предложения клиенту.

- **Платформа:** macOS 13.5+, Apple Silicon.
- **Технологии:** JavaScript, Node.js, Cocoa/WebKit.
- **Возможности:** каталог автомобилей, расчёт расходов, сохранение предложений, печать и экспорт PDF/PNG.
- **Область расчёта:** прямой ввоз юридическим лицом; результаты предварительные, ограничения описаны в проекте.

[О проекте](https://github.com/Andrles/BMW-Import) · [Скачать](https://github.com/Andrles/BMW-Import/releases/latest) · [Сообщить об ошибке](https://github.com/Andrles/BMW-Import/issues)
